# E-commerce Data Analytics Project

## Project Overview
This project focuses on analysing e-commerce business data to understand sales performance, customer behaviour and business trends.

## Tools Used
- Microsoft Excel
- SQL
- Power BI

## Project Activities
1. Data Cleaning
2. Data Transformation
3. Data Relationships
4. Data Analysis
5. Dashboard Creation

## Project Objectives
- Analyse total sales.
- Identify top-performing categories.
- Understand customer purchasing behaviour.
- Generate meaningful business insights.

## Project Status
Currently in progress.
